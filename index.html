Windows browser · Public alpha

JevBrowse

Open many.
Run few.
Keep context.

A browser where tabs are durable records and renderers are borrowed resources. Isolated workspaces, explainable tracker blocking and scoped agent permissions.

The engineering decision

Separate the lifetime of a tab from its renderer. Idle tabs can release resources while preserving their state. An internal benchmark recorded 58% less private memory after disposing four of five renderers; this is a single workload result, not a general browser comparison.

Antventure

One ant, one leaf and a river in a thunderstorm. A seeded Daily River gives players a shared course, with all art drawn in code.

The engineering decision

A 120 Hz fixed-step simulation separates game updates from rendering. A shared seed defines the Daily River, making the course reproducible.
